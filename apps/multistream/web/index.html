Stream settings in OBS / vMix

OBS: Settings > Stream > Service "Custom". vMix: Stream settings > Destination "Custom RTMP Server". Keyframe interval 2 s. For TikTok in true vertical, stream a vertical canvas to the same server with stream key vertical and set TikTok to "Vertical output".
The RTMP server restarts (live platforms drop for a moment). Windows may ask to allow it through the firewall.
